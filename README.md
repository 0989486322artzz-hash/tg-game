# Нагодуй друзів — Telegram-гра (автоклікер)

**Гра онлайн:** https://0989486322artzz-hash.github.io/tg-game/

5 друзів · 15 локацій · 131 прокачка. Усі фони вже лежать в `assets/bg/`.

## Запуск у Telegram (один раз)
1. Telegram → **@BotFather** → `/newbot` → назва → username (має закінчуватися на `bot`).
2. Токен бота нікому не показувати і не класти в цей репозиторій.
3. `/mybots` → твій бот → **Bot Settings** → **Menu Button** → вставити адресу:
   `https://0989486322artzz-hash.github.io/tg-game/` → назва кнопки, напр. `Грати`.
4. (Опційно) `/newapp` → вибрати бота → та сама адреса → отримаєш пряме посилання `t.me/<бот>/<назва>`.
5. Відкрити бота на телефоні → кнопка **Грати** → гра на весь екран.

## Оновлення гри
Змінив файли → завантажив на GitHub (гілка `main`) → через 1–2 хв гра оновиться в Telegram.
Якщо Telegram показує стару версію — закрити гру й відкрити знову.

## Що де міняти
- Цілі локацій: `js/data/locations.js` (`goal`)
- Прокачки, ціни, ефекти: `js/data/upgrades.js`
- Ріст цін, офлайн-дохід: `js/config.js`
- Друзі (рівні) по черзі: `js/data/levels.js` + `js/data/friends.js`
- Фони: `assets/bg/`

## Тест на комп'ютері
VS Code → Live Server (або `npx serve`). Подвійний клік по `index.html` не працює (JS-модулі).
`?debug=1` в адресі — кнопки +1000 $, час ×10, скинути.

## Збереження
Telegram CloudStorage (прогрес прив'язаний до акаунта) + localStorage як резерв. Автозбереження кожні 10 с і при згортанні.
